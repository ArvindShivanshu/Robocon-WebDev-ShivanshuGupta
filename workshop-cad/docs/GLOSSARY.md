# Plain-English Glossary

Simple, one-line definitions for common developer terms:

- **Repo (Repository)**: The project folder that tracks every file and historical change over time.
- **Branch**: An independent, parallel copy of the codebase where you safely build features without touching working code.
- **Commit**: A saved snapshot of changes you have made, labeled with a brief descriptive message.
- **Push / Pull**: "Push" sends your saved local snapshots up to GitHub; "Pull" downloads the newest snapshots from GitHub onto your computer.
- **Merge Conflict**: A situation where two team members changed the exact same line of code, requiring a person to decide which change to keep.
- **Environment Variable**: A secret setting or URL stored outside the code so sensitive keys are never exposed in public files.
- **Deploy**: Publishing your application files onto a live cloud server so anyone on the internet can visit the site.
- **API Key**: A unique secret password that proves your app has permission to talk to external services like Supabase or AI models.
- **Endpoint**: A specific web address on your server (like `/api/workshops`) that listens for requests and sends back data.
