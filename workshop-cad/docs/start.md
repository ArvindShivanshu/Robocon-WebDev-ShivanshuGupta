# CAD Co-Design Project — Quick Start

Welcome to the SolidWorks 3D CAD & Altium ECAD Co-Design Workshop platform.

## The Golden Path
1. Explore live lab seats for SolidWorks 3D CAD & Altium ECAD tracks.
2. Launch interactive CAD/ECAD studio: inspect 3D enclosure models and route 45° PCB traces with live DRC checks.
3. Submit attendee registration, reserve a verified seat, and receive an instant digital confirmation pass.

## The Roles
- **Surface**: Client UI, 3D CAD viewer, interactive Altium PCB layout canvas, forms, and responsive styling (`client/`).
- **Core**: Express backend API, PostgreSQL/Supabase database schema, validation, and seat deduction logic (`server/`).
- **Glue**: System integration, CORS, environment configs, task board coordination, merging to main, and Vercel deployment.
